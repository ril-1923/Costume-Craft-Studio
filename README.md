# CostumeCraft Studio
React 18 + TypeScript + Vite + Bootstrap 5 fashion storefront (portfolio demo). HashRouter, base './' for GitHub Pages.
Commands: `npm install`, `npm run dev`, `npm run typecheck`, `npm run build` (output in dist/, deploy to GitHub Pages).
Implemented: Home, Collections, Shop, Product Details, Design Studio, Custom Tailoring (cm/in conversion, review step), Gallery (lightbox), Wishlist, Cart (coupons WELCOME10, FESTIVE500, SILK15), simulated Checkout, Confirmation, My Orders, About, Contact, 404. Data persists in LocalStorage.
Limitations: demo only; no payments, emails or backend. Product images are placeholder photos (picsum.photos), not real fashion photography.
